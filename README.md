# Problematicas-de-Transporte-App

Aplicación desarrollada para resolver problemas de transporte mediante métodos de investigación operativa, facilitando la asignación de recursos entre orígenes y destinos y el cálculo de los costos asociados.

El proyecto cuenta con una **versión web** y una **aplicación de escritorio**, desarrolladas con diferentes tecnologías.

## Funcionalidades

- Resolución de problemas de transporte.
- Implementación de los métodos de Esquina Noroeste, Menor Costo y Aproximación de Vogel.
- Cálculo de asignaciones y costos totales.
- Guardado y carga de proyectos.
- Exportación de informes en PDF.
- Pruebas automatizadas de la lógica de negocio.

## Tecnologías

- C#
- .NET MAUI
- XAML
- JSON
- Visual Studio
- Inno Setup

## Arquitectura

La aplicación de escritorio está organizada en tres proyectos:

- **TransporteMAUI:** interfaz gráfica y funcionalidades principales.
- **TransporteMAUI.Core:** modelos, servicios y algoritmos de resolución.
- **TransporteMAUI.Tests:** pruebas automatizadas.

(en la carpeta comprimida de este repositorio se encuentra el código o los archivos del programa)

## Instalación

Para instalar la aplicación de escritorio, descargá el instalador para Windows desde la sección [Releases](../../releases) y seguí las instrucciones del asistente.

Para ejecutar el proyecto desde el código fuente, necesitás Visual Studio con la carga de trabajo de .NET MAUI y el SDK de .NET compatible.
